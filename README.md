# Bakhtiyar Portfolio

## Run in VS Code
1. Open the `bakhtiyar-portfolio` folder in VS Code.
2. Open `index.html`.
3. Either double-click `index.html` to open it in your browser, or install the **Live Server** VS Code extension and choose **Open with Live Server**.

## Structure
- `index.html` — portfolio content
- `assets/css/styles.css` — styling and responsive layout
- `assets/js/main.js` — menu, typing animation, header, active navigation
- `assets/img/` — add future images here

No build step or npm install is required.


## Projects section
The portfolio now includes a Projects section. The first card documents this portfolio itself as a customized responsive HTML/CSS/JavaScript project. Add future projects by duplicating the `project-card` article in `index.html`.
